# 组件化实验副本

本目录是 `TarkovMapLocator` 的组件化实验副本，基线版本为 `31.27.40`。

## 实验约束

- 组件化相关修改只在本目录进行，项目根目录中的原版源码保持不动。
- `src/TarkovMapLocatorDesktop` 必须始终能够独立构建并运行回归检查。
- 功能未完全迁出主程序集前，不在安装器中宣称该功能可以独立卸载。
- 用户数据继续保存在原有的 LocalAppData 路径；安装、移除组件不得删除用户进度与配置。
- 缺少或加载失败的可选组件只能隐藏/禁用对应入口，不能阻止核心程序启动。

## 计划模块

核心程序固定安装，负责地图、应用外壳、导航、设置、日志、前进/后退和模块发现。地图与定位是产品核心，不作为安装器可选项。

可选模块按侧栏大功能划分：

1. 市场
2. 改枪
3. 改枪 Beta
4. 战局查价
5. 任务物品清单
6. 任务追踪
7. 调色
8. 队友同步
9. 小工具

共享宿主服务保留在核心；各功能的专属程序集、原生运行库、模型、初始缓存和任务目录只随对应组件安装。

## 第一阶段验收条件

- 建立稳定的模块契约和模块目录发现机制。
- 核心程序在没有任何可选模块时仍能启动并进入设置页。
- 先迁移“小工具”作为试点，确认独立安装、移除和加载行为。
- 发布自检拆为核心自检和按组件执行的模块自检。
- Inno Setup 支持完整、精简和自定义安装，并保留升级前的组件选择。
