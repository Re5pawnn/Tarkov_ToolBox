# 塔科夫工具箱使用指南

这是一个给《Escape from Tarkov》玩家使用的 Windows 桌面地图工具。它把本机的游戏日志、坐标截图、地图、任务点、物价、OCR 识价、滤镜与局域网队友位置放在同一个程序中。

程序只读取你主动选择的截图和日志目录，不会修改游戏文件、游戏设置、截图或日志文件。

## 每次开局的最快用法

1. 启动 `TarkovToolbox.exe`。
2. 在右侧“本局状态”点击“开始监听”，再打开“自动刷新”。
3. 进入对局后，程序会根据日志自动切换地图；在游戏中按你的坐标截图快捷键（通常为 `·`）生成新的坐标截图，地图会更新当前位置。
4. 需要任务点时，在右侧“任务点位”搜索并勾选任务。
5. 需要查价时，先到“市场”刷新一次对应的 PVP 或 PVE 行情；之后可手动搜索，或进入“识价”启动游戏内 OCR 查价。

如果地图、当前位置或 OCR 没有反应，优先查看“设置 → 运行日志”，里面会记录实际读取到的路径、地图识别结果和错误原因。

## 启动与文件位置

### 便携版

双击 `TarkovToolbox.exe` 即可启动。请始终保留整个程序文件夹，不要只把 EXE 单独复制到别处；地图、任务数据、OCR 识别文件都与 EXE 同目录。

### 安装版

如果你拿到的是安装程序，按安装向导选择目录即可。安装时可选择创建桌面快捷方式。

程序为 64 位 Windows 程序。物品行情刷新需要联网；地图监听、已有缓存、任务进度和局域网共享不需要外部服务器。

## 第一次使用：必须配置两个目录

首次启动会提示配置路径，也可以随时从左下角“设置”进入“本机设置”。请选择下面两个**文件夹本身**，不要选择其中的单个文件。

1. **坐标截图目录**：存放带游戏坐标信息的 PNG 截图的目录。
   - 常见参考路径：`C:\Users\Administrator\Documents\Escape from Tarkov\Screenshots`
2. **游戏日志目录**：Escape from Tarkov 的 `Logs` 目录。
   - 常见参考路径：`D:\SteamLibrary\steamapps\common\Escape from Tarkov\build\Logs`

选择完成后，确认每一项下方显示“目录可访问”，再回到地图页面点击“开始监听”。如果你的游戏安装盘或 Windows 用户名不同，以你电脑的实际目录为准。

## 地图、当前位置与点位

### 基础操作

- 左侧列表可手动切换地图；监听到支持的地图后会自动切换。
- 鼠标滚轮缩放地图，按住鼠标左键拖动地图。
- 右下角 `+`、`−` 可缩放，`⟳` 恢复默认视图。
- 左右栏都可收起，给地图留出更大的显示区域。
- 有楼层的地图可通过顶部“楼层”下拉框选择对应楼层；仅在该地图具备楼层图时显示。
- 点击“悬浮地图”可打开独立小地图窗口，小地图同样支持滚轮缩放。

### 点位显示

点击地图顶部“点位显示”，可按需开启或关闭：

- 撤离点与转移点；
- 已勾选任务的任务点；
- 钥匙房／上锁点；
- BTR 位置预测（支持的地图才会显示）。

地图上的常用颜色含义：

- 红色箭头：当前玩家位置与面朝方向；
- 蓝色箭头：过期坐标。它仍保留在地图上供参考，等新截图到来后会恢复红色；
- 绿色：撤离点；
- 黄色：转移撤离点或 BTR 预测；
- 紫色：任务点；
- 钥匙图标：钥匙房／上锁区域。

把鼠标放在撤离点名称或图标附近，会显示该撤离点的使用条件，例如阵营、人数、钥匙、信号弹或付费要求。条件仅供游戏内核对，不会自动替你判断当前是否可用。

### 任务点位

任务点默认不显示，避免遮挡地图。

1. 选中地图后，在右侧“任务点位”搜索任务名称或目标描述。
2. 勾选想追踪的任务。
3. 已勾选任务的名称和点位会显示在地图上。
4. 点击任务旁“完成”后，该任务会从默认地图点位中隐藏；需要重新显示时可取消完成状态或清空选择。

## 空投定位

空投定位通过两次不同位置、不同朝向的坐标截图计算两条视线的交点，因此只能给出近似落点。

1. 在地图顶部点击“空投定位”，或在游戏外**单独轻按一次 `Ctrl`** 开启模式。
2. 站在 A 点，瞄准同一个空投后，按你的坐标截图键（通常为 `·`）生成一张新截图。
3. 横向移动一段距离后，在 B 点再次瞄准同一个空投，再生成一张新截图。
4. 地图会显示两条定位射线与红色估算点。

注意：`Ctrl + 左键`、`Ctrl + 右键`、`Ctrl + 滚轮` 等组合操作不会触发空投模式，避免影响游戏原有操作。两次位置不要太近，也不要让两次视线几乎平行；否则程序会提示重新取 B 点。再次单独轻按 `Ctrl`、点击“退出”或“重置”即可结束或重新开始。

## 物品查价

1. 点击左侧“市场”。
2. 选择 **PVP** 或 **PVE**。两种模式的行情和缓存彼此独立。
3. 程序启动后会尝试后台刷新；也可点击“刷新价格”立即更新。
4. 使用搜索框输入中文名、简称、英文名或物品 ID。
5. 点击某张物品卡片或“报价明细”，查看跳蚤价格、商人收购价和报价来源。

刷新失败时，程序会优先保留并显示最近一次成功的本地缓存。网络恢复后再点击“刷新价格”即可。没有缓存时，市场和 OCR 识价都无法给出实时行情。

## 任务物品数量清单

1. 点击左侧“清单”。
2. 选择 PVP 或 PVE 后点击“刷新清单”。
3. 用顶部搜索框查找物品。
4. 用物品卡片上的 `− / +` 记录当前持有数量。
5. 可切换“任务”“藏身处”“显示已完成”，并展开“来源明细”查看需求来自哪些任务或模块。

物品数量、完成状态和 PVP/PVE 选择会保存在本机。清单不读取你的游戏仓库，只记录你手动填写的数量。

## 游戏内 OCR 识价

“识价”会识别游戏内物品提示上的名称，在物品提示旁显示透明文字行情。它使用本机的市场缓存，不会把游戏截图上传到网络。

### 正常使用

1. 先在“市场”中选择与你游戏一致的 PVP/PVE 模式，并至少成功刷新一次价格。
2. 点击左侧“识价”。
3. 再次确认 PVP/PVE，点击“启动识别”。
4. 回到游戏，打开物品详情。
5. 识别成功后，物品提示旁会出现透明文字：物品名、跳蚤均价、跳蚤底价、最高收购商人和单格价值。

商人名称会自动显示为常用中文简称，例如俄商、大妈、黑商、滑雪商、美商、机械师、服装商、猎人和竞技场裁判。

### 价格文字颜色

悬浮文字按**单格价值**着色，整段文字使用同一种颜色：

- 灰色：无有效价格；
- 浅蓝色：低于 100,000 ₽／格；
- 紫色：100,000–499,999 ₽／格；
- 金色：500,000–999,999 ₽／格；
- 红色：1,000,000–9,999,999 ₽／格；
- 粉色：10,000,000 ₽／格及以上。

悬浮窗本身没有背景、边框或遮罩，只显示文字；鼠标和键盘输入仍会传给游戏。

### 自动 OCR、识别区域与定位画面

- 默认使用 PP-OCR 自动识别：打开物品检视窗口后，把鼠标停在物品名称或“重量 kg”附近即可；无需模板或 OCR 框校准。
- **识别区域**：仅在检视窗口总是出现在固定位置时使用。框选后，识别只扫这块区域。
- **清除区域** 或 **自动修复**：恢复为扫描鼠标附近；自动修复还会清除旧版定位记录。
- **查看定位画面 / 窗口化定位画面**：用于确认识别结果或反馈问题。红、绿、蓝分别表示物品标题、重量 kg 和价格悬浮窗位置。

定位画面只读：可用滚轮缩放、在空白处拖动平移，不需要也不能调整标题／重量 OCR 框。调试画面只在内存中显示，不会写进你的截图目录。

## 屏幕调色

“调色”修改的是所选显示器的系统 Gamma 曲线，不是仅修改本工具或游戏窗口。参数刻度、RGB 三通道计算顺序和最终曲线均与 Gamma Panel 一致。

1. 进入“调色”，选择预设和目标屏幕。
2. 勾选“联动 RGB”时，调整任意颜色会同步修改另外两个通道；取消勾选后可分别调整红、绿、蓝。
3. Gamma 与对比度的 `100` 等于 Gamma Panel 中的 `1.00`，亮度直接使用相同的正负整数。
4. 拖动滑块或输入数值后会实时生效；“立即应用”可以手动确认一次当前参数。
5. 不需要调色时点击“恢复系统颜色”。

程序会在第一次修改前备份原始曲线，并使用独立守护进程处理强退恢复。如果画面异常，优先点击“恢复系统颜色”。

## 队友位置共享

队友共享只适用于同一局域网，所有参与者都应在各自电脑上完成路径配置并开启监听。

### 房主

1. 进入“队友”，填写显示名称并选择标记颜色。
2. 点击“我是房主”。
3. 点击“开启房间”。
4. 把显示的 `IP:端口` 发给队友。

### 队友

1. 填写显示名称并选择颜色。
2. 点击“我要加入队友”。
3. 输入房主提供的 `IP:端口`。
4. 点击“加入队友”。

首次使用时如 Windows 防火墙询问权限，请允许程序通过**专用网络**通信。队友坐标来自各自本机的新坐标截图；过期位置不会作为实时位置共享。

## 手机地图

“手机地图”组件可把电脑端当前地图和定位实时显示在手机浏览器中。普通局域网可以直接使用；手机热点或移动网络建议配合 SakuraFrp。

卫星地图会按设备自动使用手机 2048 或平板 3072 清晰度的 WebP 资源，并使用版本化缓存；切换地图时会先在后台加载新图，减少黑屏和重复下载。

1. 在 SakuraFrp 创建 `HTTPS` 隧道，本地 IP 填 `127.0.0.1`，本地端口填 `17428`（或工具内设置的端口）。
2. 在电脑端进入“手机”，把 SakuraFrp 给出的完整连接地址粘贴到“公网入口”。
3. 点击“启动手机地图”，同时在 SakuraFrp 官方启动器中启动对应隧道。
4. 复制工具生成的“手机访问地址”，在手机浏览器中打开。
5. 手机端可拖动、双指缩放、回到当前位置，并独立开关撤离点和当前定位；转移点归入撤离点显示。

工具不会读取或保存 SakuraFrp 账户密钥，隧道由官方启动器管理。手机访问地址包含本次启动随机生成的访问码，首次访问后会立即从地址栏移除，停止服务后失效。公网入口强制使用 HTTPS；局域网服务只监听回环地址和一张私有网络接口。

## 运行日志与常见问题

### 查看运行日志

“设置 → 运行日志”提供三个实用按钮：

- **复制全部**：方便发给他人协助排查；
- **清空显示**：只清空当前界面显示，不删除历史文件；
- **打开目录**：打开按天保存的完整日志目录。

日志会记录路径读取、地图识别、坐标解析、市场刷新、OCR、滤镜和队友共享等信息。

### 不自动切换地图

1. 确认“设置”中的日志目录选到了 `build\Logs`，而不是游戏根目录。
2. 确认右侧已经点击“开始监听”，并开启“自动刷新”。
3. 进入一局后等待游戏写入新日志，再查看“运行日志”中是否有地图名称或解析失败信息。

### 没有当前位置或位置一直是蓝色

1. 确认截图目录内直接存在新的带坐标 PNG 截图。
2. 用游戏／坐标截图工具的快捷键重新生成一张截图（常用为 `·`）。
3. 蓝色表示截图已过期，位置仍可参考；新截图成功读到后会恢复为红色。

### 市场刷新或 OCR 无价格

1. 确认网络可访问行情服务。
2. 在“市场”内选择正确的 PVP/PVE，再点击“刷新价格”。
3. OCR 识价启动前必须至少有一次成功的对应模式行情缓存。
4. OCR 仍不识别时，先点“自动修复”恢复鼠标附近扫描，再查看“定位画面”；只有检视窗口固定在同一位置时才需要设置“识别区域”。

### 队友无法加入或没有位置

1. 确认双方在同一局域网，地址和端口无误。
2. 检查 Windows 防火墙是否允许本工具走专用网络。
3. 确认双方都已开始监听，并且各自都有新坐标截图。

## 本机数据与隐私

路径配置、地图任务选择、清单数量、行情缓存和运行日志保存在当前 Windows 用户的本地应用数据中。程序不会主动上传你的截图、游戏日志或个人文件；只有你主动开启队友共享或手机地图时，才会向对应的局域网连接或 SakuraFrp 隧道提供地图与实时位置数据。
