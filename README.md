# 塔科夫工具箱

当前主程序是原生桌面版。最新版运行文件直接位于 `TarkovToolbox`，可维护源码位于 `src`，历史内容统一归档在 `legacy`。

- 最新程序：`TarkovToolbox/TarkovToolbox.exe`
- 桌面版源码：`src/TarkovMapLocatorDesktop`
- 用户使用说明：`TarkovToolbox/README.md`
- 历史版本、源码与旧工具：`legacy`

直接运行 `TarkovToolbox/TarkovToolbox.exe` 即可启动当前版本。

在 `src/TarkovMapLocatorDesktop` 中运行 `publish-portable.bat`，会直接覆盖更新 `TarkovToolbox` 主程序目录，不再生成额外的版本子目录。
