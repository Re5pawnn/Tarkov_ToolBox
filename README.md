# 塔科夫工具箱

一个给《Escape from Tarkov》玩家用的小工具。功能主要包括地图定位、撤离点、任务追踪、物品查价、游戏内 OCR 识价、屏幕调色、队友位置、手机地图和实用功能。

工具不会修改游戏文件。地图定位依靠游戏日志和坐标截图；无反作弊风险。

最新版本：[前往 Releases 下载](https://github.com/Re5pawnn/Tarkov_ToolBox/releases/latest)

## 首次使用

第一次使用需要先在“设置”里选好两个目录：

- **坐标截图目录**：通常是 `%USERPROFILE%\Documents\Escape from Tarkov\Screenshots`
- **游戏日志目录**：游戏安装目录下的 `Escape from Tarkov\build\Logs`
选好目录后点击“开始监听”，然后按游戏内截图键进行定位，截一次图更新一次位置。

## 下载与安装

程序支持 64 位 Windows，正式发布包已经包含运行所需环境，不需要另外安装 .NET。

安装器提供三种方式：

- **完整安装**：地图和所有功能都装上，第一次使用建议选这个。
- **精简安装**：只安装核心程序和地图。
- **自定义安装**：自己选择需要的功能。

## 地图与实时位置

地图为核心必装功能。

- 左侧地图列表可以手动切图，开始监听后能根据游戏日志自动切换。
- 支持内置 2D 地图和卫星地图。
- 鼠标滚轮缩放，按住左键拖动；右下角按钮可以放大、缩小和复位。
- 有楼层数据的地图可以手动选层，也可以打开“自动切层”。
- “悬浮地图”会打开一个独立小窗，位置和尺寸可以调整并锁定。

### 点位显示

地图顶部的“点位显示”可以单独控制：

- 撤离点和转移点
- 已选择的任务点
- 钥匙房和上锁点
- 拉闸点
- 赛季文件
- BTR 位置预测（灯塔尚未支持）

鼠标停在撤离点或钥匙房上，可以查看阵营、钥匙、信号弹、付费等条件。它们是查询信息，最终能不能撤离以当局游戏内为准。

玩家箭头变成蓝色，表示目前显示的是一张较旧的坐标截图。重新生成坐标截图后会恢复成实时颜色。

### 地图任务点

右侧“任务点位”默认不会显示。需要玩家手动搜索任务名称或目标，勾选需要的任务即可。

“任务”页面里的“标记任务时同步地图任务点位”也可以完成同样的事。电脑端选中的任务点会同步到手机网页地图。

### 空投定位（目前不太好用）

空投定位需要两次坐标截图，用两条视线的交点估算落点：

1. 保持工具箱在“地图”页面，点击“空投定位”，或单独轻按一次 `Ctrl`。
2. 在 A 点瞄准空投，生成第一张坐标截图。
3. 横向移动一段距离（最好是一大段距离，两次位置不要太近，视线也不要几乎平行），在 B 点重新瞄准同一个空投，再生成一张截图。
4. 地图会画出两条射线和估算落点。


## 物品查价

进入“市场”，先选择 **PVP、PVE 或赛季服**，再点击“刷新价格”。刷新期间页面顶部会显示进度条。

搜索框支持中文名、简称和英文名。展开“报价明细”可以查看跳蚤价格、24 小时行情和商人报价。不同模式的缓存互相独立；刷新失败时会保留最近一次成功的数据。

市场数据也是 OCR 识价、任务物品和藏身处利润的价格来源。准备使用这些功能前，最好先把对应模式的市场行情刷新一次。

## 游戏内 OCR 识价（占用内存较高）

“识价”会读取游戏内物品检视窗口，在旁边显示透明的价格文字。识别和截图处理都在本机完成。

正常用法：

1. 先在“市场”刷新与你游戏一致的 PVP、PVE 或赛季服行情。
2. 进入“识价”，选择相同模式，点击“启动自动识别”。
3. 回到游戏后双击打开物品详情，把鼠标停在“重量 kg”附近。
4. 识别成功后会显示物品名、跳蚤价格、商人收购价和单格价值。

默认自动扫描鼠标附近。连续识别不到时，请点击“自动修复”。
## 任务物品清单

“清单”可以记录任务和藏身处还缺多少东西：

1. 选择 PVP 或 PVE，点击“刷新清单”。
2. 用搜索框找到物品，通过卡片上的 `− / +` 填写当前持有数量。
3. 展开“来源明细”，可以看到需求来自哪个任务或藏身处设施，也能把某条来源标成完成。

工具不会读取你的游戏仓库，这里的数量需要手动维护。记录会保存在本机，下次打开还在。

## 备忘录

“备忘”分成文字备忘和物品备忘。文字会自动保存；物品可以按名称或简称搜索后加入，并填写数量。

打开“显示悬浮窗”后，备忘内容会显示在独立小窗里，适合放本局要找的物品、任务顺序或临时提醒。

## 任务追踪（目前自动识别任务不太可用，只能识别到部分任务）

“任务”页面提供 PVP、PVE 和赛季服任务树，可以按商人和关键词筛选，也能拖动、缩放整个任务关系图。

- 任务状态可以手动设为“未接取、进行中、已完成”。
- “自动识别任务”会根据游戏新写入的日志同步状态。
- “自动补全前置任务”会在完成后续任务时补齐已满足的前置任务。
- “标记任务”可把任务放进悬浮窗。
- 勾选“标记任务时同步地图任务点位”后，对应点位会同时显示在电脑地图和手机地图上。
- “查看攻略”里可以查看目标、前后置任务、所需钥匙和奖励。

自动识别依赖正确的游戏日志目录。如果刚改过路径，先回地图页确认监听正常，再点“立即同步”。

## 屏幕调色



**Gamma Panel（小蝴蝶）** 可以直接应用小蝴蝶的参数，效果相同。

**自动滤镜** 会分析截图后调整画面，可选择预设、平滑切换以及“仅游戏前台生效”。不想继续使用时点击“恢复系统颜色”。

## 队友位置共享（依赖SakuraFrp）

队友位置来自每个人自己的坐标截图。所有人都要先配好截图、日志目录，并在地图页开始监听。房主端建议同时安装“队友位置共享”和“手机地图”组件，因为两项功能共用同一个服务端口。

### 房主

1. 在“手机”页面确认共享端口，默认是 `17428`。
2. 进入“队友”，填写自己的名称和标记颜色。
3. 选择“我是房主”，设置一个至少 12 位的房间密钥。
4. 点击“开启房间”。如果共享服务还没启动，程序会自动启动。
5. 把房主地址和房间密钥通过可信渠道发给队友。

### 加入房间

1. 填写自己的名称和颜色，选择“我要加入队友”。
2. 同一局域网填写房主提供的穿透后的内网穿透地址。
3. 公网连接可以直接填写房主的完整 `https://` 手机地图地址。
4. 填写与房主相同的房间密钥，点击“加入队友”。

首次使用时，如果 Windows 防火墙询问权限，请允许程序通过专用网络。过期坐标不会继续作为实时位置发送。

## 手机地图（依赖SakuraFrp）

手机网页会跟随电脑端的当前地图、楼层、当前位置、任务点和队友位置。手机上可以拖动、双指缩放、回到当前位置，也可以独立开关撤离点、任务点、当前位置和队友。

### 同一局域网

1. 电脑和手机连接同一个路由器或热点（手机热点目前不可用 除非你能解决隔离）。
2. 进入“手机”，点击“启动共享服务”。
3. 点击“复制地址”，把地址发到手机上并用浏览器打开。

### 使用 SakuraFrp（推荐）

只需要建立一条隧道，手机地图和队友位置共享都走这一个端口：

1. 在 SakuraFrp 创建 **TCP** 隧道，端口选择`17428`,开启自动https，点击创建隧道。
2. 启动隧道，把 SakuraFrp 提供的地址前面加上完整 `https://` 地址粘贴到“公网入口”。
3. 点击“启动共享服务”，再复制工具生成的手机访问地址。

手机地址带有本次启动随机生成的访问码。浏览器第一次访问后会把它保存到当前会话，地址栏中的访问码会被移除；停止共享服务后旧地址失效。

## 小工具

“小工具”里目前有四项：

- **邪教圈配方**：按祭品或奖励搜索配方。
- **赛季文档刷新位置**：查询文档刷新点、地图和所需钥匙。
- **藏身处利润**：按 PVP、PVE、赛季服行情计算成本、利润和每小时利润，支持筛选与排序；刷新时会显示进度条。
- **剧情攻略**：按模式查看剧情任务的解锁条件、步骤和配图。

## 常见问题

### 地图不自动切换

- 检查日志目录是否选到了 `build\Logs`，不要选游戏根目录。
- 确认地图右侧已经开始监听并打开自动刷新。
- 进入一局后等游戏写入新日志，再到“设置 → 运行日志”搜索“地图”。

### 没有当前位置，或者箭头一直是蓝色

- 检查截图目录里有没有新生成的 PNG。
- 重新按一次坐标截图键。
- 蓝色只表示截图较旧，不代表地图损坏。
- 检查是否打开了自动切层。

### 市场或 OCR 没有价格

- 检查网络，并确认选择了正确的 PVP、PVE 或赛季服模式。
- 在“市场”手动刷新一次；OCR 必须先有对应模式的行情缓存。
- OCR 不识别时先点“自动修复”，再看定位画面。

### 队友加入失败

- 房主和队友必须使用完全相同的房间密钥。
- 同一局域网使用房主的私网 `IP:端口`；跨网络使用完整 HTTPS 地址。
- 检查双方监听状态、坐标截图和 Windows 防火墙。
- 房主端需要安装手机地图组件，统一的共享服务才能启动。

### 左侧少了某个功能

该功能是可选组件。重新运行安装器，选择“自定义安装”，勾选需要的组件即可。

### 怎么反馈问题

打开“设置 → 运行日志”，可以按级别、模块和关键词筛选，也可以复制显示内容、导出日志或打开完整日志目录。反馈时请说明使用的模式、出现问题的页面和大致时间，以及完整的屏幕截图，排查会快很多。

## 数据保存与隐私

配置、任务进度、清单数量、行情缓存和运行日志保存在当前 Windows 用户的：

`%LOCALAPPDATA%\TarkovMapLocatorDesktop`

程序不会主动上传坐标截图、游戏日志或 OCR 画面。只有主动开启手机地图或队友共享时，当前地图和实时位置才会通过你指定的局域网连接或隧道发送。
